# Iris Flower Classification

A multi-class classification model that identifies iris flower species from physical measurements — a foundational ML project demonstrating end-to-end classification pipeline design.

## Problem Statement
Classify iris flowers into three species (Setosa, Versicolor, Virginica) based on sepal and petal dimensions. A classic ML benchmark used to demonstrate feature separability, model comparison, and evaluation best practices.

## Dataset
- **Source:** UCI Iris Dataset (one of the most widely used ML datasets)
- **Records:** 150 samples (50 per class)
- **Features:** 4 numerical — sepal length, sepal width, petal length, petal width (cm)
- **Target:** 3 classes — Iris Setosa, Iris Versicolor, Iris Virginica

## Methodology
1. **EDA** — pairplots, correlation analysis, class distribution
2. **Preprocessing** — train/test split, feature scaling
3. **Model Training** — classification model(s) with Scikit-learn
4. **Evaluation** — accuracy score, classification report
